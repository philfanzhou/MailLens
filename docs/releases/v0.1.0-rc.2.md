## Purpose and changes

This RC supplies an immutable schema-2 candidate for native Windows/Classic
Outlook validation in [#9](https://github.com/philfanzhou/MailLens/issues/9).
Live validation is **pending**; hosted synthetic tests and OpenCode discovery
certify neither live Outlook speed/read-only behavior nor model correctness.
Pending #9 is an acknowledged RC limitation. Stable `v0.1.0` remains gated on
completed #9, exact-candidate human signoff and separate final stable
version/SHA/publication authorization in [#11](https://github.com/philfanzhou/MailLens/issues/11).

Changes since immutable rc.1:

- [PR #32](https://github.com/philfanzhou/MailLens/pull/32): direct bounded
  Inbox browse, ten-subject default, no global catalog or body preflight;
  lightweight connection-only diagnose.
- [PR #33](https://github.com/philfanzhou/MailLens/pull/33): schema-2 scoped
  search/folders with finite shared budgets, truthful partial/count/coverage
  reporting, sender/subject checks before Body, capped aggregate warnings,
  coarse date filtering and disclosed bounded fallback. Query schema 1 is
  rejected before COM; receipts retain their independent schema 1.
- [PR #34](https://github.com/philfanzhou/MailLens/pull/34): bounded skill flow,
  no routine diagnose/catalog preflight, at most ten initially selected
  summaries and explicit 2000-scalar first body chunks, with stalled/denied
  stop rules and deliberate additional scope/chunks.
- RC version and source-publication/installation status are synchronized under #35.

Distribution: complete Git source snapshot and GitHub automatic source archives.
No standalone binary, extra release asset, package registry or marketplace.
