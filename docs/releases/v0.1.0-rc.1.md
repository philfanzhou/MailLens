## Purpose and channel

`v0.1.0-rc.1` is a prerelease candidate published under #25's recorded
maintainer direction so a maintainer can install an immutable candidate on
native Windows and perform live Classic Outlook validation in
[#9](https://github.com/philfanzhou/MailLens/issues/9). Live Windows/Classic
Outlook validation is **pending**: this RC is not evidence of a passed live
test, and synthetic hosted checks and OpenCode discovery do not certify live
Outlook or model behavior. Pending #9 is an acknowledged RC limitation, not a
publication blocker. Stable `v0.1.0` remains gated on completed #9 with human
signoff and separate final version/SHA/publication authorization in
[#11](https://github.com/philfanzhou/MailLens/issues/11).
