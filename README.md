# MailLens

A read-only OpenCode skill for searching and analyzing Classic Outlook email on Windows through local COM automation.

MailLens is in development and has no published release. [VERSION](VERSION) is
`0.1.0`, an unpublished development baseline, not an available release or
installation target. The first release targets OpenCode on native Windows with
Classic Outlook and Windows PowerShell 5.1; implementation and validation are
tracked in [the first-release plan](https://github.com/philfanzhou/MailLens/issues/1).

See [CONTRIBUTING.md](CONTRIBUTING.md) for project boundaries, language, encoding,
privacy and version conventions. MailLens is licensed under [MIT](LICENSE).
